# Third-party code, data and references

This project is GPL-3.0-or-later ([LICENSE](LICENSE)). It contains **no game data** and **nothing from the
Microsoft XDK**. This file lists everything it uses or learned from that is not its own, and how.

## Included in the repository

| What | Where | License | How it is used |
| --- | --- | --- | --- |
| RenderDoc in-application API header, by Baldur Karlsson | `port/third_party/renderdoc/renderdoc_app.h` | MIT (header kept intact) | Optional frame captures (F11) when RenderDoc is installed |
| Xbox kernel export list from [nxdk](https://github.com/XboxDev/nxdk) (`xboxkrnl.h`), by Stefan Schmidt and contributors | `src/ngb_tools/data/xboxkrnl_exports.tsv`, generated `port/src/kernel/stubs.c` | CC0 | Ordinals, names and signatures of the kernel exports the port reimplements |
| [Josefin Sans](https://github.com/googlefonts/josefinsans) Thin, Light and SemiBold, by Santiago Orozco | `port/res/fonts/JosefinSans-*.ttf` | SIL OFL 1.1 (`port/res/fonts/OFL-JosefinSans.txt`), unmodified | Latin type of the launcher, embedded in `ngb-launcher.exe` |
| [Shippori Mincho B1](https://github.com/fontdasu/ShipporiMincho) SemiBold, by FONTDASU, reduced to the 22 kanji the launcher draws | `port/res/fonts/ShipporiMinchoB1-SemiBold-kanji.ttf` | SIL OFL 1.1 (`port/res/fonts/OFL-ShipporiMincho.txt`), subset (no Reserved Font Name) | Kanji ornaments of the launcher, embedded in `ngb-launcher.exe`; how the subset is made is in `port/res/fonts/README.md` |

## Code that follows another project

| Project | License | What follows it |
| --- | --- | --- |
| [xemu](https://github.com/xemu-project/xemu) | The files the port follows (`hw/xbox/nv2a/`, `hw/xbox/mcpx/apu/`) are LGPL, version 2 or later (checked in their headers); compatible with GPL-3.0-or-later | The NV2A model (`port/src/gpu/`): push-buffer processing, PGRAPH state, method names and offsets (`nv097_names.c`, from `nv2a_regs.h`), the fixed-function lighting and texture conversions. Also parts of the OpenGL back end (`port/src/gl/`) and of the APU voice processor (`port/src/apu/`). Comments in those files point to the xemu behavior they reproduce. |

The NV2A vertex and pixel shader translators (`port/src/shaders/vsh.c`, `psh.c`) were written from the hardware
documentation. They consulted xemu, Cxbx-Reloaded and envytools but copy no code from them.

## References (facts only, no code or text copied)

- [Cxbx-Reloaded](https://github.com/Cxbx-Reloaded/Cxbx-Reloaded) (GPL-2.0-or-later): XBE layout, the EEPROM
  setting indices and the loader technique of running the XBE inside a Win32 process.
- [XboxDevWiki](https://xboxdevwiki.net/): XBE format, kernel, EEPROM and input devices.
- [envytools](https://github.com/envytools/envytools) (MIT): NV2A register and shader documentation.
- [OpenCE](https://github.com/punpckhdq/halo): prior art for rebuilding an Xbox game without the XDK.
- [AFSLib](https://github.com/MaikelChan/AFSLib) and [Sewer56/AfsLib](https://github.com/Sewer56/AfsLib): the CRI
  AFS container format.
- [extract-xiso](https://github.com/XboxDev/extract-xiso) and [Ghidra](https://github.com/NationalSecurityAgency/ghidra):
  external tools used during development. Neither is included.
