# ninja-gaiden-black-port

Proyecto **pedagógico y sin fines comerciales** para aprender ingeniería inversa y portado de
juegos: llevar Ninja Gaiden Black (Xbox original) a ejecución nativa en PC.

- **No incluye ningún dato del juego.** Hace falta una copia propia.
- Documentación y estado del proyecto: el vault de Obsidian en `docs/`. Se empieza por
  `docs/GOAL-ngb-port.md`.
- Herramientas en `tools/` (Python 3.13, solo stdlib). Tests: `python -m unittest discover -s tests -v`.

Ninja Gaiden es una marca de Koei Tecmo. Este proyecto no está afiliado ni respaldado por Koei
Tecmo, Team Ninja ni Microsoft.
